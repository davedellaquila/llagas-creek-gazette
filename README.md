# The Llagas Creek Gazette

The running record of the sale of **18231 Llagas Creek Dr, Morgan Hill, CA 95037** — compiled from listing agent Kay Korbel's reports and invoices to the sellers (Dave, Ron and Emile Dell'Aquila): the work, the money, and what happens next.

- Live paper: https://davedellaquila.github.io/llagas-creek-gazette/
- Single-page static site (`index.html`, no build step), published via GitHub Pages from the repo root on `main`.
- Source digest the first edition was compiled from lives outside the repo (Astro's workspace: `llagas-creek-gazette/source-digest.md`).
- Ships the fleet-standard newspaper photo lightbox (tap any story photo → full-screen viewer with prev/next and count).
